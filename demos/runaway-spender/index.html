The Runaway Spender, Contained

The commerce twin of The Runaway, Contained: an autonomous agent settles an in-scope buy, then goes rogue twice — over the spend ceiling, then to a vendor outside its envelope. Both are held before the wallet is ever asked to authorize them, and the run resumes. Each step's allow/block is computed by the real spend branch of checkConformance from kcp-harness.

Set the envelope, then press ▶ Run autonomous agent. The gate decides each buy before it settles — and never stops the loop.
